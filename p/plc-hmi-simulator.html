Client Project

PLC Training Simulator — Industrial Water Treatment

Modbus TCP simulator behind a live operator HMI · US automation client

Operators train startup, fault injection and recovery with no plant hardware

Robotics Engineer · consulting

Overview

Built a Windows-based Modbus TCP simulator that stands in for the PLC behind a water-treatment client's existing operator HMI, so staff can be trained without tying up real plant equipment. The simulator runs a sequence-of-operations state machine with a packed alarm catalogue, and serves all four Modbus register spaces from one shared cache. Every address the HMI binds is either published or has a recorded reason not to be, enforced by an automated coverage test against the client's own tag database. Instructor controls let any home-screen process value be held, and the held value is folded into ground truth before the physics reads it, so the simulated plant genuinely responds to it. A live parameter view exposes the controller's data table in the operators' own order, with the settable rows editable in place. The build runs an automated wire-level acceptance pass against the executable it just produced, so a broken build cannot ship.

What it does

  • Sequence-of-operations state machine with a packed alarm catalogue
  • Modbus TCP server across all four register spaces from one shared cache
  • HMI tag-binding coverage enforced by automated tests against the client tag database
  • Instructor hold controls folded into ground truth so the plant responds to them
  • Automated wire-level acceptance run by the build against the produced executable
