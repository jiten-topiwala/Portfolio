Client Project

Unitree Go2 — Stand & Walk Controller

Quadruped stand-up and trot in MuJoCo · client delivery

Stand-up and trot gait with live IMU and joint telemetry — CPU only, no GPU

Robotics Engineer · consulting

Overview

Controller that brings a Unitree Go2 quadruped from a resting pose to a stable stand and then a forward trot, running in the unitree_mujoco simulator over the Unitree DDS interface. Built to run on CPU alone with no GPU requirement, and reports IMU and joint-state telemetry live so the gait can be inspected while it runs. Delivered with run scripts and setup instructions.

What it does

  • Stand-up sequence to a stable standing pose
  • Forward trot gait
  • Live IMU and joint-state telemetry readout
  • Runs on CPU alone — no GPU required
  • Delivered with run scripts and setup instructions
