Client Project

Quadruped Locomotion Control — Unitree Go2

Gait control for a Unitree Go2 in MuJoCo · client delivery

Stand-up and forward trot with live IMU and joint telemetry — CPU only, no GPU

Robotics Engineer · consulting

Overview

Locomotion control for a Unitree Go2 quadruped, running in the unitree_mujoco simulator over the Unitree DDS interface. The controller takes the robot from a resting pose to a stable stand and then a forward trot, and reports IMU and joint-state telemetry live so the gait can be inspected while it runs. Built to run on CPU alone with no GPU requirement, and delivered with run scripts and setup instructions.

What it does

  • Stand-up sequence to a stable standing pose
  • Forward trot gait
  • Live IMU and joint-state telemetry readout
  • Runs on CPU alone — no GPU required
  • Delivered with run scripts and setup instructions
