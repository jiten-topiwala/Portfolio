Client Project

Mobile Manipulator Pick & Place — MuJoCo

MORPH-I tripod manipulator in MuJoCo · obotx, Poland

Base, 8-DOF arm and 11-DOF gripper all motion-planned

Robotics Engineer · consulting

Overview

Freelance project (client in Poland, obotx). Built an end-to-end OMPL motion-planning pipeline for the MORPH-I mobile manipulator in MuJoCo: RRT-based (x, y, yaw) planning for the mecanum base, an 8-DOF parallel-manipulator planner with per-state MuJoCo collision checks for the arm grasp, and RRT-Connect over the 11-DOF gripper joint space. Whole-body motion economy (wrist to arm to base priority), closed-loop control (measured per-finger contact forces, position-feedback placement servo, base correction from the measured residual), and predictable, honest failure handling. One press runs the full cycle: drive to object, plan and execute the grasp, transport, place on the shelf slot, and return to HOME. Dockerised on Ubuntu 22.04.

What it does

  • OMPL RRT base navigation (x, y, yaw) for a mecanum mobile base
  • 8-DOF arm grasp planner with per-state MuJoCo collision checks
  • RRT-Connect gripper (11-DOF) open/close trajectory planning
  • Closed-loop: contact-force grasp confirmation + position-feedback placement
  • Whole-body motion economy (wrist to arm to base) with clean failure handling
