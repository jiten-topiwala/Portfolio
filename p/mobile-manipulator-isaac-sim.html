Client Project

Mobile Manipulator Pick & Place — NVIDIA Isaac Sim

MORPH-I tripod manipulator in NVIDIA Isaac Sim · obotx, Poland

Closed-chain arm stock planners cannot model — solved with OMPL and a custom validity checker

Robotics Engineer · consulting

Overview

Second build for the same mobile manipulator, this time in NVIDIA Isaac Sim on OpenUSD. The MORPH-I arm is a closed kinematic chain, which stock planners such as MoveIt, Lula and cuMotion cannot model — so planning runs on OMPL with a custom state-validity checker written against the robot's real structure. The grasp is friction-only: the object is held by contact rather than being attached to the gripper in software, so the simulation reflects whether the grasp would actually hold. Plans are re-validated against measured state at checkpoints during execution rather than trusted once at planning time. Delivered and accepted September 2026.

What it does

  • OMPL planning with a custom validity checker for a closed-chain arm
  • Friction-only grasp — held by contact, not a software attach
  • Checkpoint re-validation against measured state during execution
  • OpenUSD scene and robot description in NVIDIA Isaac Sim
  • Stock planners (MoveIt, Lula, cuMotion) ruled out and worked around
