Client Project

Conversational Humanoid for Live Events — Unitree R1

Cloned voice, camera awareness and gesture dispatch on a 26-DOF robot · US client

Holds a conversation with a crowd and gestures while it speaks — run from a phone page

Robotics Engineer · consulting

Overview

Built and deployed an interactive character system on a 26-DOF Unitree R1 humanoid for live event performances. The robot listens through a directional microphone with adaptive noise handling, answers in a cloned voice, uses its camera to answer questions about the people and things in front of it, and dispatches matching gestures while it speaks. Gesture dispatch was proven against the robot model in MuJoCo before ever moving real joints, then brought to hardware in stages — tethered, reduced speed, then full. The operator drives everything from a phone web page: persona and topic notes, speech, movement toggles and audio routing. Shipped as a compiled on-robot build with a written handoff and run sheet.

What it does

  • Cloned-voice speech with adaptive microphone noise handling
  • Camera-based look responses to people and objects in view
  • Gesture dispatch proven in MuJoCo simulation before running on hardware
  • Phone web interface for persona, speech, movement and audio routing
  • Compiled on-robot deployment with handoff documentation and run sheet
