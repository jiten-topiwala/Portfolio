Robocon 2023 — Ring Toss

Two robots for ring shooting on poles using dual-roller mechanism

5th all-India · 2nd at MATLAB Modelling Award · automated shooting via simulation-derived data

Mechanism + Control + Vision · competition · 2022-10

Overview

Participated in Robocon 2023 (ring toss in pole game). Brainstormed many mechanism concepts, prototyped the strongest candidates, then finalised a dual-roller ring-shooting mechanism for accuracy and precision. Used CNC machining, sheet-metal working, and 3D printing — and designed parts as per each manufacturing process. Designed an internal-gripper for picking ring stacks. One robot used mecanum wheels, the other omni wheels. Performed MATLAB and Simulink modelling of both robots — generated motion, tested shooting mechanisms for design validation, simulated base drives for path-planning, and integrated contact forces and other physical parameters so the simulation matched the real robot. Automated shooting in MATLAB: ran simulations to capture the ring's estimated trajectory, then used data analysis to choose input parameters that put the ring into the pole automatically based on its position and the detected pole position. Built laser-and-camera-based pole detection and top-most-ring colour detection via image processing. Built the control system in MATLAB; the robots were semi-autonomous. Team finished 5th all-India and 2nd at the MATLAB Modelling Award.

What it does

  • Dual-roller ring-shooting mechanism finalised after prototyping
  • Mecanum-wheel and omni-wheel base drives
  • Internal-gripper design for picking ring stacks
  • MATLAB/Simulink full robot modelling with contact forces
  • Automated shooting via simulation-derived parameter dataset
  • Laser + camera pole detection and ring-colour detection (image processing)
  • Multi-process manufacturing: CNC, sheet metal, 3D printing
